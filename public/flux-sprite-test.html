How this works:
1. SMB CHR-ROM sprite tiles extracted (pattern table 0, 256 tiles)
2. Rendered as 128×128 grid → upscaled 512×512
3. FLUX Kontext transforms to medieval fantasy style
4. Downscale → per-tile NES palette quantization → 2bpp CHR
5. PPU renders from ptTile[] cache, NOT vramMem directly
   Fix: use ppu.writeMem() to update both vramMem + ptTile
   Persistent: re-writes ptTile via setScanline() every frame

Controls: Arrow keys + Z (jump) + X (fire/run)
