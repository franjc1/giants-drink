How this works:
1. SMB OAM captured across 230 frames → 14 unique character groups
2. Composed into 960×120 sprite row PNG (3× scale)
3. FLUX Kontext transforms to medieval knight style
4. Per-tile extraction → NES palette quantization → 2bpp CHR
5. PPU renders from ptTile[] cache, NOT vramMem directly
   Fix: use ppu.writeMem() to update both vramMem + ptTile
   Persistent: re-writes ptTile[0-255] via setScanline() every frame
   SMB sprites at PT0 ($0000); BG at PT1 ($1000) — ppuFlags.spPatternTable=0

Controls: Arrow keys + Z (jump) + X (fire/run)
